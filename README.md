# Banking-Data-Analysis-and-Visualization-Project
Project Overview:

This project focuses on performing complete Data Analysis and Business Intelligence on a banking dataset using Python, MySQL, and PowerBI.
The goal of the project was to clean raw banking data, analyze customer and financial trends, generate meaningful business insights and create an interactive dashboard for decision-making.

Objectives:
- clean and preprocess raw banking data
- perform feature engineering for better analysis
- perform exploratory data analysis (EDA)
- Store cleaned data in MySQL
- Execute SQL queries for business analysis
- create interactive Power BI dashboard
- generate actionable business insights and report
- generate ppt using gamma for presentation
- Build a complete analytics project

Tools & Technologies used:
- Python: Data cleaning & EDA
- Pandas: Data manipulation
- Matplotlib & Seaborn: statistical visualizations
- Jupyter Notebook (Google Colab): development environment
- MySQL: Database & SQL analysis
- Power BI: Dashboard and visualization
- Gamma: generating ppt
- GitHub: project hosting & version control

Project Workflow:
1. Data Collection
2. Data cleaning & Preprocessing
3. Exploratory Data Analysis
4. SQL analysis
5. Power BI dashboard
6. Generating Report & Insights

Key Insights:

- Debit transactions dominated customer activity, indicating that customers used bank facilities for out-going transactions more rather than incoming money.
- Transaction amounts were highly positively skewed. Most of the customers did transactions for low-to-medium amounts and few customers did significantly higher transactions.
- Most customers completed login in a single attempt indicating good operational efficiency.
- Branch, ATM, and online channels all showed significant usage indicating multi-channel engagement by customers.
- Adult and middle-aged customers contributed higher financial activity and account balance.
- A small number of customers maintained significantly high account balances, especially from doctor professionals.
- Monthly transaction values fluctuated throughout the year. 
- Total transaction amount dropped significantly from March-April and rise again from April-May indicating customer financial behaviour.
- Highest total transaction amount recorded is in September Month, of total ~$73,000.
